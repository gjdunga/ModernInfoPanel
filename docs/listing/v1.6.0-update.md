# Codefling update-notes blurb — v1.6.0

Paste-ready copy for the Codefling listing's **update notes** box when posting the
v1.6.0 update. Three formats below: plain text, BBCode (Codefling/IPS editor), and a
one-liner for a forum title or short box. Source of truth for the changelog is
[`CHANGELOG.md`](../../CHANGELOG.md); the full listing pack is
[`CODEFLING.md`](../../CODEFLING.md).

---

## Plain text

**Modern Info Panel v1.6.0 — Admin editor, per-player timezones & a theming kit**

This release closes the last gaps from the feature review — all still dependency-free (Oxide + Carbon, 8 languages, free/GPL-3.0).

**🛠 In-game admin editor — `/mipanel admin`**
Tune your HUD live, in-game, no config diving and no ImageLibrary. For every panel you get an ON/OFF toggle, `<`/`>` to move it between the four corner docks, `w-`/`w+` to nudge its width, and a row of background-color swatches. Toggle whole docks on/off too. Every change saves and redraws instantly, so the editor and your config never drift.

**🕓 Per-player timezones — `/mipanel tz America/Denver`**
Players can pin their clock to any named IANA timezone, DST-correct year-round. Persists across reconnects; `/mipanel tz off` reverts to the server clock. (Resolves on Linux/mono hosts out of the box.)

**🎨 Theming kit**
A new `THEMING.md` guide (color model, the Status-glow palette, swapping in your own icon art, and copy-paste Dark / Neon / Minimal presets) plus a layered, editable `panel-template.svg` to build a matching icon set.

Drop the updated `ModernInfoPanel.cs` into `oxide/plugins/` — your existing config carries over untouched.

📦 Source & full changelog: https://github.com/gjdunga/ModernInfoPanel/releases/tag/v1.6.0
